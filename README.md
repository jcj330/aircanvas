# 空中画板 AirCanvas

基于电脑摄像头手部追踪的"空中绘画"互动网页。伸出一根食指，对准镜头在空中比划，指尖轨迹就会实时绘制成画——握拳暂停、握拳保持 1 秒切换橡皮擦、张开手掌停止待机。

除了自由画板，还带两个辅助模块：**模仿挑战**（照着线稿画，自动打分）和**我的画廊**（保存作品、大图回看）。

## 三个模块

| 模块 | 说明 |
|---|---|
| 自由画板（主） | 全部绘画功能：手势绘制、橡皮、10 色、粗细、撤销重做、清空、暂停、导出 PNG、存入画廊 |
| 模仿挑战 | 内置 8 张卡通线稿（星星/房子/小鱼/冰淇淋/大树/小猫/小鸡/雨伞），照着画完点「提交评分」，得到 0–100 分与三色重合图 |
| 我的画廊 | 保存的作品以缩略图排列，点开看大图，可左右切换、下载、删除；作品存在浏览器本地 |

首页主卡进入自由画板，下方两张小卡分别是模仿挑战和我的画廊。顶栏左上角「← 首页」可随时切回，**来回切换不会重开摄像头，画板上的内容也会保留**。

## 运行环境

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome 或 Edge（推荐，版本 80+）；Firefox 可用但体验略差 |
| 硬件 | 一个可用的摄像头（笔记本自带即可） |
| 网络 | 首次运行需联网加载手部追踪模型（约 3 MB，之后有浏览器缓存） |
| 安装 | **无需安装任何软件、无需构建步骤** |

## 怎么运行

### 方式一：直接双击（推荐）

双击打开 `index.html`（默认会用 Chrome / Edge 打开）：

1. 点击页面上的「启动体验」按钮；
2. 浏览器弹出摄像头权限询问时，选择「允许」；
3. 等待模型加载完成（首次约几秒到十几秒，取决于网速）；
4. 回到首页后选一个模块，把手伸到镜头前，伸出食指即可开始绘画。

### 方式二：本地服务器（备用）

若你的浏览器在直接双击打开时无法唤起摄像头（个别浏览器会拦截 file:// 页面的摄像头权限），用下面任意一种方式启动本地服务：

**有 Python**（在项目文件夹打开终端）：

```bash
python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`

**有 VS Code**：安装 Live Server 插件 → 右键 `index.html` → Open with Live Server

## 手势操作对照

| 手势 | 效果 |
|---|---|
| ☝️ 伸食指 | 绘制（当前工具为画笔）或擦除（当前工具为橡皮擦） |
| ✊ 握拳 | 暂停抬笔，可移动手而不画线 |
| ✊ 握拳保持 1 秒 | 在画笔 / 橡皮擦之间来回切换 |
| 🖐️ 张开手掌 | 停止待机 |
| 手离开画面 | 1.5 秒后进入待机 |

## 工具栏功能

画笔/橡皮切换 · 10 色色板 · 粗细调节（2–30 px）· 撤销/重做（Ctrl+Z / Ctrl+Y，最多 25 步）· 两段式确认清空 · 暂停/恢复追踪 · 导出 PNG · 存入画廊

挑战模式的工具栏另外有「提交评分」和「换一幅」；换题目时如果画布上已经有内容，需要再点一次确认，避免误清。

## 模仿挑战怎么评分

评分只看**线条位置和覆盖程度**，不看颜色：

1. 把参考线稿和你的画布都缩到 240×180 的二值掩膜；
2. 对参考线做 Chamfer 3-4 距离变换，得到"每个像素到最近参考线的距离"；
3. 精确度 = 你的每一笔墨迹到参考线的平均距离，用 `CONFIG.SCORE.tauPx`（默认 30 掩膜像素）映射成 0–100；
4. 完整度 = 你的墨量 / 参考墨量，低于 85% 按比例扣分，超过 250% 再乘 0.85 抑制乱涂刷分；
5. 得分 = 精确度 × 完整度，四舍五入取整。

结果面板里的三色图：**蓝 = 只有参考线**、**红 = 只有你的笔迹**、**白 = 两者重合**。想调松紧就改 `tauPx`（调大更容易得高分）。

## 画廊的存储说明

画廊有**两种模式**，由「有没有登录」自动决定，上层代码完全一样：

### 未登录：存在浏览器本地

作品存在浏览器 `localStorage`（键名 `aircanvas.gallery.v1`），最多 40 张，单张按 640×480 JPEG 压缩、另存一张 240×180 缩略图，全部作品合计约 2–5 MB。

- 换浏览器、换电脑、清理浏览器数据都会导致作品丢失；
- 存满或空间不足时程序会自动淘汰最旧的几张，并弹出提示；
- 无痕模式下浏览器不允许写入，会明确提示"保存失败"，不会静默丢数据。

### 已登录：存在 Supabase 云端

- 作品图片上传到 Storage 桶 `artworks`，路径 `{用户id}/{作品id}_full.jpg`，一行记录写进 `artworks` 表；
- 换任何一台电脑、任何一个浏览器，登录同一个账号，画廊里就是同一批画；
- 第一次登录时会自动把本机已有的作品同步上去（同步成功后清空本机，避免重复）；
- 未登录时画廊顶部会显示"仅本机，登录后可跨设备"。

## 账号与云同步（可选，需要自己配 Supabase）

**不配置也完全能用** —— 页面会自动走本地存储模式，登录按钮不出现，其它功能一点不受影响。

配置四步：

1. 打开 [supabase.com](https://supabase.com)，用邮箱注册，新建一个免费项目（Region 选 Singapore 或 Tokyo 更快），等它初始化完成约 2 分钟；
2. 左侧「SQL Editor」→ New query → 把项目根目录的 `supabase_setup.sql` 整段粘进去 → Run。看到 `artworks 表已就绪`、`artworks 存储桶已就绪 / true`、`自动确认邮箱已开启 / 1` 三行就对了；
3. 左侧「Project Settings」→「API Keys」，复制 **Project URL** 和可发布密钥（`anon public` 的 `eyJ...`，或新版 `sb_publishable_...`）两个值，填进 `index.html` 里 `CONFIG.SUPABASE` 的 `URL` 和 `ANON_KEY`。

关于第 2 步里的邮箱确认：本站的用户名会被拼成虚拟邮箱（`用户名@aircanvas.app`），收不到验证信，而项目默认开启「Confirm email」，注册后会卡在待验证状态。新版后台把这个开关从 Email 面板里移走了，所以脚本改用**数据库触发器** `trg_auto_confirm_new_user` 在注册时自动把邮箱标记为已验证，效果等同关闭该开关，不用再去界面里找。

重载页面后右上角就会出现「登录 / 注册」。用户名只支持 2–20 位字母、数字、下划线（会被拼成 `用户名@aircanvas.app` 当登录标识）。

几个要知道的点：

- **anon key 放前端是安全的**。它只标识"这是哪个项目"，不带任何数据权限；真正的隔离靠数据库的 RLS 策略，每条策略都写了 `auth.uid() = user_id`，别人即使拿到 key 也读不到你的画。
- **没有找回密码功能**。密码由你保管，忘了只能去 Supabase 后台手动重置。
- 免费项目**连续 7 天没有任何请求会被自动暂停**，打开后台点一下 Resume 即可，数据不丢。
- 免费额度：数据库 500 MB + 存储 1 GB。按每张作品约 100 KB 算，能存一万张左右。

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 弹出权限询问后点错成"拒绝" | 点击地址栏左侧的相机/锁形图标 → 摄像头设为「允许」→ 刷新页面 |
| 提示"当前浏览器在此打开方式下无法访问摄像头" | 该浏览器拦截了本地文件的摄像头权限：改用 Chrome/Edge 双击打开，或用方式二启动本地服务器 |
| 提示"摄像头被其他程序占用" | 关闭腾讯会议、Zoom 等正在使用摄像头的程序后重试 |
| 模型加载失败 | 检查网络连接后刷新页面重试（模型来自 CDN） |
| 识别不到手 / 手势乱跳 | 保证光线充足、手完整出现在画面中、距离镜头 40–80 cm；避免逆光 |
| 笔迹抖动明显 | 已内置 One Euro 自适应滤波，若仍明显可在代码中调大 `CONFIG.EURO.minCutoff`（如 1.5） |
| 提交评分只有几分 | 笔迹离参考线太远或只画了一小部分。先描外轮廓再补内部，画笔粗细建议 6–10 px |
| 保存时提示"空间不足" | 画廊已满或浏览器配额不足：到「我的画廊」删掉几张旧作品，重要作品先点「下载」 |
| 换了浏览器作品不见了 | 没登录时作品只存在当前浏览器本地；登录账号后作品在云端，换到任何设备都能看到 |
| 注册后提示"待验证"、登录不了 | `supabase_setup.sql` 里的自动确认触发器没跑上：去 SQL Editor 重新整段执行一次，跑完已有账号也会被一起确认 |
| 右上角没有「登录 / 注册」 | `CONFIG.SUPABASE` 里的 `URL` / `ANON_KEY` 还没填，或填错了一位 |
| 保存到画廊时提示"上传失败" | 检查网络；确认 Supabase 项目没被暂停（免费项目连续 7 天无请求会自动暂停，后台点 Resume 恢复） |
| 画板切回来内容没了 | 只会在切换题目（挑战模式）或点「清空」时清空；若刷新过页面则无法恢复，重要作品请及时保存 |

## 实现结构速览（index.html 内 16 个模块）

1. UI 结构与样式 —— 深色玻璃拟态界面、四视图布局
2. 全局配置 `CONFIG` —— 所有可调参数集中一处（含评分与画廊参数）
3. CDN 多源容错加载器 —— jsdelivr 失败自动切 unpkg，按需加载不卡启动
4. 摄像头管理器 —— 点击启动后才申请权限，错误分类提示
5. 手势识别器 —— 21 关键点掌宽归一化判定 + 连续 4 帧稳定器
6. 状态机 —— 绘制/暂停/橡皮擦/停止/待机的转移逻辑
7. One Euro 滤波器 —— 低速强滤波防抖、高速弱滤波保流畅
8. 绘图引擎工厂 —— 两块画布各一套实例，二次贝塞尔中点插值平滑笔迹
9. 撤销/重做工厂 —— ImageData 快照双栈，两块画布互不干扰
10. 通用 UI —— toast、状态徽章、指尖光标、工具栏工厂
11. 视图路由 + 舞台吸附 + 主循环 —— 唯一的视频舞台按槽位定位，循环带代次守卫
12. 导出与作品快照 —— PNG 导出、JPEG 大图 + 缩略图
13. 模仿挑战 —— 8 张内置线稿、Chamfer 距离变换评分、三色重合图
14. 账号与我的画廊 —— Supabase 登录 / 云端存储 / 本地回退、网格 + 灯箱
15. 主流程编排 —— 每帧识别 → 手势稳定 → 状态机 → 滤波 → 绘制
16. 页面入口 —— 事件绑定与键盘快捷键

关键算法均有中文注释，可按模块编号在 `index.html` 内直接定位阅读。
