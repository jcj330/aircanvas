# 空中画板 AirCanvas

基于电脑摄像头手部追踪的"空中绘画"互动网页。伸出一根食指，对准镜头在空中比划，指尖轨迹就会实时绘制成画——握拳暂停、握拳保持 1 秒切换橡皮擦、张开手掌停止待机。

## 运行环境

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome 或 Edge（推荐，版本 80+）；Firefox 可用但体验略差 |
| 硬件 | 一个可用的摄像头（笔记本自带即可） |
| 网络 | 首次运行需联网加载手部追踪模型（约 3 MB，之后有浏览器缓存） |
| 安装 | **无需安装任何软件、无需构建步骤** |

## 怎么运行

### 方式一：直接双击（推荐）

双击打开 `index.html`（默认会用 Chrome / Edge 打开）：

1. 点击页面上的「启动体验」按钮；
2. 浏览器弹出摄像头权限询问时，选择「允许」；
3. 等待模型加载完成（首次约几秒到十几秒，取决于网速）；
4. 把手伸到镜头前，伸出食指即可开始绘画。

### 方式二：本地服务器（备用）

若你的浏览器在直接双击打开时无法唤起摄像头（个别浏览器会拦截 file:// 页面的摄像头权限），用下面任意一种方式启动本地服务：

**有 Python**（在项目文件夹打开终端）：

```bash
python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`

**有 VS Code**：安装 Live Server 插件 → 右键 `index.html` → Open with Live Server

## 手势操作对照

| 手势 | 效果 |
|---|---|
| ☝️ 伸食指 | 绘制（当前工具为画笔）或擦除（当前工具为橡皮擦） |
| ✊ 握拳 | 暂停抬笔，可移动手而不画线 |
| ✊ 握拳保持 1 秒 | 在画笔 / 橡皮擦之间来回切换 |
| 🖐️ 张开手掌 | 停止待机 |
| 手离开画面 | 1.5 秒后进入待机 |

## 工具栏功能

画笔/橡皮切换 · 10 色色板 · 粗细调节（2–30 px）· 撤销/重做（Ctrl+Z / Ctrl+Y，最多 25 步）· 两段式确认清空 · 暂停/恢复追踪 · 导出 PNG

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 弹出权限询问后点错成"拒绝" | 点击地址栏左侧的相机/锁形图标 → 摄像头设为「允许」→ 刷新页面 |
| 提示"当前浏览器在此打开方式下无法访问摄像头" | 该浏览器拦截了本地文件的摄像头权限：改用 Chrome/Edge 双击打开，或用方式二启动本地服务器 |
| 提示"摄像头被其他程序占用" | 关闭腾讯会议、Zoom 等正在使用摄像头的程序后重试 |
| 模型加载失败 | 检查网络连接后刷新页面重试（模型来自 CDN） |
| 识别不到手 / 手势乱跳 | 保证光线充足、手完整出现在画面中、距离镜头 40–80 cm；避免逆光 |
| 笔迹抖动明显 | 已内置 One Euro 自适应滤波，若仍明显可在代码中调大 `CONFIG.EURO.minCutoff`（如 1.5） |

## 实现结构速览（index.html 内 12 个模块）

1. UI 结构与样式 —— 深色玻璃拟态界面
2. 全局配置 `CONFIG` —— 所有可调参数集中一处
3. CDN 多源容错加载器 —— jsdelivr 失败自动切 unpkg，按需加载不卡启动
4. 摄像头管理器 —— 点击启动后才申请权限，错误分类提示
5. 手势识别器 —— 21 关键点掌宽归一化判定 + 连续 4 帧稳定器
6. 状态机 —— 绘制/暂停/橡皮擦/停止/待机的转移逻辑
7. One Euro 滤波器 —— 低速强滤波防抖、高速弱滤波保流畅
8. 绘图引擎 —— 二次贝塞尔中点插值平滑笔迹、落笔涟漪反馈
9. 撤销/重做 —— ImageData 快照双栈（上限 25 张）
10. 工具栏交互 —— 色板、滑块、两段式清空确认、快捷键
11. PNG 导出 —— 深色底合成作品图
12. 主流程编排 —— rAF 主循环 + 每帧识别→状态机→滤波→绘制

关键算法均有中文注释，可按模块编号在 `index.html` 内直接定位阅读。
